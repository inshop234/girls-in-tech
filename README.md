## Girls-in-tech

A beginner-friendly creative coding playground built with HTML, CSS, and JavaScript. This repo is a personal learning space for experimenting with web design, visual art, and simple interactive front-end projects.

## What is in this repo?

This repository currently includes:

- a simple personal landing page (`girls-in-tech`)
- a README documenting the learning process and project goals
- beginner-focused experiments in styling, layout, and front-end design

## Current project

The main project in this repo is a personal webpage that introduces the creator, shares a bit about their learning journey, and acts as a first web project built during Code Ignite.

## Tech used

- HTML
- CSS
- JavaScript
- Git and GitHub

## How to run locally

There is no build step required.
