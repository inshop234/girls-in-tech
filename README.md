# Girls in Tech

A small collection of beginner creative coding experiments built with HTML, CSS, and p5.js. This repo documents a learning journey exploring generative art, animations, and simple web-based visuals.

## Included projects

- Hypnotic flowers
- circling circles <>
- cubes animation
- girls-in-tech personal landing page

These are static browser-based sketches and pages, designed to be easy to open and experiment with.

## Tech used

- HTML
- CSS
- JavaScript
- p5.js

## How to run locally

There is no build step required. Each sketch is a simple static webpage.

1. Clone the repository:

```bash
git clone https://github.com/inshop234/girls-in-tech.git
cd girls-in-tech
```

2. Start a local web server:

```bash
python3 -m http.server 8000
```

3. Open the relevant file in your browser. For example:

```text
http://localhost:8000/
```

To view a specific sketch, place the appropriate HTML/JavaScript/CSS files in the same directory and open the HTML file in a browser.
